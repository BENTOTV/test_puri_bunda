# Disclaimer

Inline note banner: `info` (the not-medical-advice note), `warn` (rate-limit countdown) and `err` (offline, load-more failure).

- 20px icon + `footnote` text, `radius-sm`, soft fill with its matching ink (≥5.7:1).
- The info note appears at the end of every detail screen. Warn/err banners sit above the list and don't replace content already loaded.
